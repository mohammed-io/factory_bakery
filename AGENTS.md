# FactoryBakery

A Ruby gem that fills ActiveRecord (and ActiveModel-compatible) objects with fake data driven by validation heuristics, inspired by Python's model-bakery.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (`mohammed-io/factory_bakery`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels are used verbatim (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root, created lazily by `/domain-modeling`. See `docs/agents/domain.md`.
